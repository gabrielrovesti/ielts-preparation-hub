# Recurring Error Patterns — Italian Interference

Consolidated from verified writing sessions. Each row traces to at least one real session; this is not a generic ESL error list.

## Lexical Resource

| Incorrect | Correct | Mechanism |
|---|---|---|
| "demanded to [person]" | "passed on to [person]" / "demanded that [clause]" | *domandare* false cognate; "demand" doesn't take "to + person" as a recipient |
| "provide equally [service]" | "provide [service] equally" | adverb placement — Italian post-verbal adverb order intrudes on English SVO+adverb conventions |
| "very expensive" / "very [basic adjective]" | "costly," "prohibitively expensive," "substantial," "negligible" | over-reliance on "very" as sole intensifier caps Lexical Resource at band 7 regardless of accuracy elsewhere |
| "embark in" | "embark on" | preposition collocation error |
| "volunteering to [activity]" | "volunteering for [activity]" | preposition collocation error |
| "pragmatica approach" | "pragmatic approach" | Italian adjective ending intruding under time pressure |

## Grammatical Range and Accuracy

| Pattern | Example | Fix |
|---|---|---|
| Gerund chaining | multiple gerunds stacked without a finite verb anchoring the clause | break into separate finite clauses or use one gerund + one relative clause |
| Indirect question word order | "ask what will you have to do" (main-clause inversion retained) | "ask what you will have to do" — no inversion in embedded questions |
| Run-on from fused draft sentences | two competing main verbs joined without a connector (e.g. "should be X... may represent Y") | pick one main verb per sentence; use "and," "which," or a full stop |
| Adverb placement (see lexical table) | — | — |

## Task Achievement / Response — GT Letter Task 1 specifically

The 7.5 → 8.0 ceiling for GT Task 1 is **not** driven by grammar or lexis — it's driven by four structural features, confirmed against externally-scored Band 8 and Band 9 samples:

1. **Named institution/course/person** where the task allows it, instead of a generic reference.
2. **Causal justification with a stated consequence** for any conflict/complaint, not just an assertion that something can't be changed.
3. **A precise, narrow rescheduling or resolution window** (same-day, next-morning) rather than a vague multi-day offer.
4. **Follow-up questions layered one clause deeper** than the bare task requirement (e.g. not just "is there a test" but "if so, which topics").

This is now a standing benchmark applied to all Task 1 model answers in this repository (see `w1-002-interview-reschedule.md` for the reference implementation).
